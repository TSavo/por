# Working on this repository

The browser port of SSI's *Pool of Radiance* (GOG version 1.3), with new Enhanced artwork and one-narrator
narration. Several agents work on `main` at once. This file is how to pick up any open item with nothing
but GitHub and this repository.

## Where the work is

- **Every open item is a GitHub issue.** The pinned issue **#71** is the index: what to install, what is
  being worked and by whom, what waits on the owner, what is unclaimed. **#103** defines the release
  candidate and lists what blocks it.
- Labels: `shipped-game` (wrong or missing on screen when playing from `game/`, the port's own data with no
  original files), `release`, `windows`, `narration`, `display`, `classic`, `tests`, `owner` (needs the
  owner's decision or accounts).
- **Claim before you start:** comment "Taking this" on the issue and remove its `ready` label
  (`gh issue edit N --remove-label ready`), so `ready` always means unclaimed. **Post as you go**, with commits and
  numbers. **Close from the commit** with `Fixes #N` and the evidence. Anything new you find is its own
  issue, filed at once.
- `docs/ART-WORKLIST.md` (generated by `npm run art:worklist`) is the art agent's list; owner requests go in
  `qa/art-requests.json`. `qa/findings.json` is history; new defects go to issues.

## How to work (the owner's rules)

- **Push at once.** Commit after `npx tsc --noEmit -p .` and `node --check` on changed JavaScript;
  `git fetch && git rebase origin/main && git push origin HEAD:main`. Main moves every few minutes.
- **Nothing is a gate.** A long check never holds a push; run it afterwards and fix forward.
- **No sleep of any kind** (no `sleep`, no `time.sleep`, no wait loops). A long step runs in the
  background with a log; do other work until it reports.
- **Run games on Battleaxe, never on the owner's Mac** (see below). Chrome always `--headless --mute-audio`.
- Red then green: show a fix's check failing before the fix and passing after, from **both** data sources
  (the GOG 1.3 files and `game/`) where it applies.
- Measure, don't list: for a class of defect, build the count first (done / total, red while anything is
  left), then work it down. Existing counts: `npm run qa:visits` (areas and commissions compared),
  `npm run verify:held-portraits` (#131), `npm run verify:enhanced-fallbacks` (#142),
  `npm run qa:narration` (#98), `npm run qa:version-1.3` (the 1.3 measure),
  `npm run qa:repeat-presses` (replay steps that press until the screen changes, #76),
  `npm run qa:instruction-diff` (every translated instruction against the original's bytes under Unicorn,
  #91; needs `POR_GAMEDATA_1_3` and Python with capstone and unicorn, `~/por-venv` on Battleaxe),
  `npm run qa:pause-callers` (every call that pauses with a message, verified when a replay from both
  sources puts that message on the page, #81; evidence from `tools/record-pause-callers.mjs`;
  after recording a walk, run `node tools/record-pause-callers.mjs --untraced` on Battleaxe and commit
  `qa/pause-callers.json`),
  `npm run verify:dos-calls` (every DOS function the translated program can ask for is served, #83).
- Commit messages: a short imperative summary; the body says what was run and seen.

## Running on Battleaxe

`ssh battleaxe` is Ubuntu (WSL) on a 32-CPU machine with plenty of memory but a slow USB root disk, so
**work trees live in RAM, under `/dev/shm`** (lost if WSL restarts: copy anything you record back at once).
Set up once, with your own short NAME:

```sh
ssh battleaxe 'git -C ~/por-qa fetch -q && git -C ~/por-qa worktree add --detach /dev/shm/por-wt-NAME origin/main && ln -s ~/por-qa/node_modules /dev/shm/por-wt-NAME/node_modules'
```

For each run, from your checkout (edit and commit where you like):

```sh
rsync -a --delete --exclude node_modules --exclude out --exclude .git ./ battleaxe:/dev/shm/por-wt-NAME/
ssh battleaxe 'cd /dev/shm/por-wt-NAME && <env> npm run -s <check> > run.log 2>&1; echo exit $?'   # in the background
```

Run the typecheck there too. Many agents share the machine: at most one heavy run of yours at a time. If
ssh says "Session open refused", add `-o ControlMaster=no -o ControlPath=none`.

On Battleaxe: the 1.3 files `POR_GAMEDATA=$HOME/por-assets/gog-1.3/POOLRAD`; the first release
`$HOME/por-assets/pool` (`qa:version-1.3` needs `POR_GAMEDATA` on the first release and
`POR_GAMEDATA_1_3` on 1.3); audio `POR_AUDIO_DIR=$HOME/por-assets/original`; Chrome `/usr/bin/google-chrome`
(add `--enable-unsafe-swiftshader` where WebGL is needed); check free ports with `ss -ltn`. Its root disk
is a USB drive: avoid needless reinstalls. A Python segfault with no traceback there is the CPU; re-run once.

## Starting points

- **Saves:** `qa/fixtures/` holds recorded walks and their saves (`campaign-*-leg`, `visit-*`, `walk-*`,
  `wilderness-walk`) and `qa/fixtures/campaign-full/` the full campaign's slot saves (A to I) and each
  leg's boot keys and commands. `tools/record-walk.mjs` records a new walk against the shipped game;
  the parity check's `leg` walk replays one (`POR_PARITY_ONLY=leg POR_PARITY_LEG=qa/fixtures/<walk>`).
- **Docs:** `docs/STANDALONE.md` (the shipped game, `verify:port-parity`), `docs/REPLAYS.md`,
  `docs/RELEASE.md` (packages, installers, what was tested), `docs/AUDIO.md`, `docs/NARRATION-QA.md`,
  `docs/ART-WORKLIST.md`, `docs/RENDERER.md` (Enhanced WebGL look).

## The owner's standing decisions

- The shipped game needs no original files and always starts in Enhanced; the player's own 1.3 files only
  unlock the Classic display. **Enhanced never falls back to an original picture** (in the shipped game a
  fallback is a blank view).
- Classic is the original game exactly. Timing and speed are not a priority, but what the player sees must
  stay on screen long enough to register (approaches, animations).
- Narration: one narrator voice performs every character, like a DM; every passage is narrated audibly at
  its moment, the dynamic ones too; the game's text is the caption.
- The code wheel comes up when the game asks for it (start-up, runes on screen, the friend-word) and can
  be put away and brought back; there is no always-on wheel button.
- Licensing and distribution rights are handled by the owner's lawyers: do not raise them.
