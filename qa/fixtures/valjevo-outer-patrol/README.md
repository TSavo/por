# Valjevo outer patrol and sentry replays

`disguised-B.json` starts west of the outer patrol route with the disguise
flag set. `B.json` clears only that flag, allowing the hostile captain
response from the same route. `sentry-B.json` starts at (10,10) facing south
and reaches the dungeon sentry and alarm. Run each with GOG 1.3 and bundled data.
