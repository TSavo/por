# Slums hobgoblin dialogue replays

Use `council-B.json` with `slums-hobgoblin-council-loop` and
`gold-room-B.json` with `slums-hobgoblin-gold-room-loop` in
`tools/verify-slums-presentation.mjs`. Run each in Chrome with GOG 1.3
and bundled data. Each replay checks the approach, the held portrait
at its dialogue cue, and the handoff to combat.
