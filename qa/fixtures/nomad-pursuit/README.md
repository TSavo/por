# Nomad Camp pursuit

Slot A stages the original pursuit on the rim of the camp at (8,2), facing north. It comes from nomad-headman-rally/A.json, with exactly one save payload byte changed. The completed-fight count at ECL global 0x4a7f (payload offset 767) is 2 instead of 3. The party, location, starting distance, clock, and other flags are copied. The original script uses this count to select the pursuit before the rally.

Up reaches (8,1) and the caption about the increasing ranks. Enter brings up Combat, Wait, Flee and Advance while the far actor remains in place. From this checkpoint both Combat and Flee reach the original battle notice. Enter then opens the battlefield.

The fixture checks the two pursuit art scopes at 9da2/a09b and 9959/a09f against both data sources.
