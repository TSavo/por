# Valhingen wight patrol

Slot A is the historical controlled patrol save for the area around (11, 5).
Run the valhingen-wight-roam-noticed replay with A.json in each data mode. The first
Parlay moves from surprise to the "You are noticed" encounter menu.
The second Parlay opens the original stance menu.

The same save also runs `valhingen-wight-roam-direct` with fixed clock
`4320891`. The direct "You find some undead" encounter shows the wight on
Advance, then opens the stance menu on Parlay.
