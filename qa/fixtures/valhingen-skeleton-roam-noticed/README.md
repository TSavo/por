# Valhingen skeleton patrol

Slot A is the historical controlled patrol save for the area around (3, 6).
Run the valhingen-skeleton-roam-noticed replay with A.json in each data mode. The first
Parlay moves from surprise to the "You are noticed" encounter menu.
The second Parlay opens the original stance menu.

The same save also runs `valhingen-skeleton-roam-direct` with fixed clock
`4320891`. It reaches "You find some undead" directly. Advance reveals
the skeleton portrait and Parlay opens the stance menu.
