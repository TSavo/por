# South of Kuto's Well

Slot J starts at (7,8) facing north. It was saved through the game's
Encamp and Save menus after walking from the versioned Kuto scouts B
slot. The route is Right, Up, Right, Up, Right, Up, Left, Up five times,
Left, Up twice, Left.

The reinforcements replay resolves the first combat using the existing
test victory control. It then waits at the original prompt for the
second wave and presses Enter once to see the next battle notice.
