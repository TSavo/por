# Valjevo sentinel alarm replay

Slot B starts before the armed sentinel by the scriptorium. The checkpoint
places the party at (6,1) facing west in the original Valjevo maze save.
`valjevo-sentinel-alarm` checks the sentinel’s approach, the alarm portrait,
and the battle notice. Enter hands off to the original first combat turn.
Run with both GOG 1.3 and bundled data.
