# Valjevo maze patrol replays

The save starts at (12,3) facing west. `disguised-B.json` has the in-game
disguise. `B.json` clears that single flag to reach the hostile branch.

Run `valjevo-maze-patrol-hostile` to check the captain’s approach, combat
menu, and battle notice. Run `valjevo-maze-patrol-disguise` to check the
same captain challenging the party and letting them pass after the password.
Run both with GOG 1.3 and bundled data.
