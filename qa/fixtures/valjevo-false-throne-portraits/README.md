# False throne portrait replays

Slot B starts outside the false throne room in Valjevo Castle. Run
`valjevo-false-throne` to check the audience, confession, release and
treasure. Run `valjevo-false-throne-dismissal` to check the warning and
retreat. Use both `POR_GAME_SOURCE=original` and `POR_GAME_SOURCE=port`
with `tools/verify-slums-presentation.mjs` and this checkpoint. Set
`POR_HELD_PORTRAIT_CHROME_TRACE` to record the holds.
