# Kuto kobold scouts

Slot B is the historical Kuto scout checkpoint used in the
kuto-sickly-kobold-scouts replay. Pass B.json to
kuto-kobold-scouts-sneak-off for the original encounter menu that follows
the initial scout warning. Run with GOG 1.3 and bundled data.

The opening-plea, pleading, and questioned replays use the same slot.
They turn east and cross between (5, 2) and (6, 2) until the scouts
appear. The last eastward step faces a wall, so the original encounter
offers Parlay. Choose Parlay and Nice, then Enter for the first choice
or Question for the second.
