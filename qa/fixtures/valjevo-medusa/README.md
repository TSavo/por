# Valjevo Medusa replay

`B.json` starts the party at (11,6) facing south outside the Medusa's
statue room. Run the `valjevo-medusa-phases` route in
`tools/verify-slums-presentation.mjs` with this checkpoint and Chrome.
The route checks her approach, the held portrait cycle, and the pose
that carries into the battle notice when the player chooses Combat.
Run it with GOG 1.3 and bundled data.
