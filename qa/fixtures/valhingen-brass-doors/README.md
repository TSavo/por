# Valhingen brass doors replay

Slot A starts at (10,3) facing east. `valhingen-shadow-beyond-brass-doors`
walks to (9,1), plays the shadowy figures’ attack at the doors, and checks
that the painting stays visible until the party enters combat. The original
sequence draws two approach sprites and never opens a full portrait.
Run with both GOG 1.3 and bundled data.
