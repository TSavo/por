# Valjevo forge patrol portrait replays

Slot B starts in the castle forge sector before the patrol intercepts the
party. The disguised copy carries the in-game disguise flag. Replay
`valjevo-forge-patrol` for the hostile challenge and its battle handoff, or
`valjevo-forge-patrol-disguise` for the password challenge and peaceful
passage. Run each with original and port data and set
`POR_HELD_PORTRAIT_CHROME_TRACE` to capture the held captain portraits.
