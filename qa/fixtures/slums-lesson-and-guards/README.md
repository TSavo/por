# Slums goblin lesson and orc guards

Use `goblin-lesson-B.json` with `slums-goblin-lesson-approach` and
`orc-guards-B.json` with `slums-orc-clash` in
`tools/verify-slums-presentation.mjs`. Run each replay with GOG 1.3
and bundled data. The replays check the approach sprite and the native
order and timing of the held dialogue portrait.

Use `orc-papers-B.json` with `slums-orc-papers-portrait-loop` and
`orc-home-B.json` with `slums-orc-home-portrait-loop`. Those replays
check the held portrait at each dialogue cue and the transition to the
battle notice when the party acknowledges it.
